# Grade Calculator

A C++ program that calculates a student's final average and displays
whether the student passed or failed.

## Features

1. Accepts three grades
2. Calculates the average
3. Displays Passed or Failed

## How to Run

1. Compile the program
2. Run the executable
3. Enter three grades
